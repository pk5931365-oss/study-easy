# Study Easy — MVP

Slogan: "Keep study easy and affordable"

This is a working browser/mobile-web MVP that can be opened locally and later wrapped into an Android app.

Included:
- NEET, JEE Main, JEE Advanced, CDS, NDA, UPSC CSE, Railway and SSC
- Easy / Medium / Hard levels
- Daily 10
- Mock test
- Timer
- Score and accuracy
- Streak
- Progress history
- ₹50/month Premium screen
- Responsive mobile UI
- LocalStorage for demo progress

Important production steps:
1. Add a much larger, carefully verified question bank.
2. Add authentication and a real backend.
3. Add Google Play Billing for the ₹50/month subscription.
4. Add AdMob only after implementing consent/privacy requirements.
5. Add current-affairs content through a properly licensed/maintained source.
6. Test every question and explanation before release.
7. Create privacy policy, terms and Play Store listing.

The ₹50 button in this MVP is intentionally a demo; it does not process real money.
